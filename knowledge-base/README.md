## Resumen Ejecutivo

JavaMaster es plataforma gratuita en español para aprender Java con práctica en navegador. El MVP publica 52 lecciones + 208 ejercicios funcionando sin backend (costo cero), sin secretos en repo y sin reactivar el executor vulnerable. Login/DB van después.
